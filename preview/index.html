Interactive Preview

Sheen Notes in the browser

A faithful, clickable recreation of the actual Android app (Jetpack Compose UI), rendered here so you can see and feel the design without a device or emulator.

  • Kashmir winter palette — frosted whites, ice-blue accents, midnight-slate dark mode
  • Live search across titles and note bodies
  • Rich-text editor — bold, italic, underline, bullet lists
  • Staggered note grid, shared-axis transitions, FAB → editor morph
  • Theme toggle persisted in the browser, seeded with sample notes
This is a UI mock of the app's Compose screens — the real app persists notes offline via Room and builds to an Android APK. Build the real thing with ./gradlew :app:assembleDebug after installing the Android SDK. The preview stores edits in localStorage.
